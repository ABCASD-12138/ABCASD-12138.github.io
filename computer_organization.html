DEFINITION (1)

微程序

有序微指令的集合。
一种存储在控制存储器（CM）中的“底层固件”。

微指令

控制存储器中的一个单元。
在一个CPU周期内发出，包含一组并行的微命令。

DEFINITION (2)

微命令

控制信号（发送端）。
例如：打入脉冲、电位控制信号。

微操作

执行动作（接收端）。
例如：(PC)+1 → PC，(R0) → MAR。

核心设计准则

  • 互斥性 (Exclusivity):
    同段内的微命令不可并行执行，物理上由译码器保证。
  • 状态留白 (Status 000):
    必须包含一个“无动作”编码（全0），代表该字段不发出任何信号。

微程序控制器硬件全景 Hardware Architecture

核心循环 (Core Cycle)

微程序执行本质是一个闭环逻辑：当前微指令决定下一条地址，新地址回流至入口，驱动持续动作。

主要部件

包括控制存储器(CM)、微指令寄存器(CMDR)、微地址寄存器(CMAR)及形成逻辑。

控制存储器 (CM) 详解 Control Memory

存储矩阵可视化

控制存储器（CM）是微程序控制器的“灵魂”。所有的微指令按地址排列在矩阵中。

下址形成逻辑

微程序的执行顺序由“微地址形成部件”控制。它可以根据微指令的 顺序字段 或 机器指令操作码 进行跳转。

微指令标准结构

24位水平型格式

指令字长定为 24 Bit。水平型微指令能够在一个微周期内控制多个硬件部件，具有极高的并行效率。

结构化字段划分

通过科学划分操作控制、判别测试和下址字段，实现了控制逻辑与存储逻辑的完美解耦。

零延时控制

操作码部分映射直接对应控制线电平，无需二级译码，响应延迟达到纳秒级级别。

操作控制字段 (23-6)

占据 18位 空间。每一位直接对应数据通路中的一个微命令信号，这种“一位对一令”的映射方式，使硬件能够瞬间响应，是高性能控制器的首选。

1. 入口寻址

机器指令的操作码经映射产生微程序的起始地址。这是宏指令进入微指令序列的起点。

2. 读取控存

微地址送入 μMAR 后，从控制存储器 (CM) 读取对应的微指令。包含当前节拍的所有控制电平。

3. 执行与下址

μOP 字段发出硬件控制信号，同时 μBA (下址字段) 指明下一条微指令的位置。

4. 循环闭环

在微程序序列末尾，地址通过反馈回路送回 μMAR，实现微指令间的连续自动执行。

取指微指令 (Fetch)

微程序起始于 0000 地址。首先完成指令提取：PC送地址总线，从内存读入指令至IR，并完成PC自增。

算术转换逻辑

通过 P₁ 测试 进入十进制加法核心：

  • R1 + R2: 基础数据相加
  • R2 + R3: 引入修正量（如：十进制校正）

状态条件判别 (P₂)

根据进位标志 Cᵧ 进行条件转移：

  • 若 Cᵧ = 0：执行减法修正 (R₂-R₃)，确保符合十进制编码。
  • 若 Cᵧ = 1：直接跳过修正，完成本轮微程序执行。
