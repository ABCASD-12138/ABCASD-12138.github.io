无向网邻接表类模板AdjListUndirNetwork

核心拓扑存储架构

封装无向网核心元数据，vexNum 存储顶点数，并由 vexTable 指针统一管理链式邻接表头数组

动态遍历标记数组

提供可变标记数组 tag，作为算法运行时的辅助缓存区，安全、无污染地动态记录顶点遍历状态

辅助 DFS 遍历策略

递归扫描起点 v 的首弧 firstarc 及其邻边链表，回溯遍历所有未访问邻接点 p->adjVex，用于连通区域高效计数

template <class ElemType, class WeightType>
class AdjListUndirNetwork {
protected:
    int vexNum, vexMaxNum, arcNum;
    AdjListNetWorkVex<ElemType, WeightType> *vexTable;
    mutable Status *tag;
    WeightType infinity;

    // 辅助：DFS遍历（用于求连通分量数目）
    void DFS(int v, bool* visited) const {
        visited[v] = true;
        for (AdjListNetworkArc<WeightType> *p = vexTable[v].firstarc; p != NULL; p = p->nextarc) {
            if (!visited[p->adjVex]) DFS(p->adjVex, visited);
        }
    }
};

顶点度数统计CountDegree(v)

索引边界安全验证

若顶点索引 v 小于 0 或大于等于最大顶点数 vexNum，则返回错误，防止越界访问

链表迭代计数机制

定义临时工作指针获取该节点的首条边 firstarc，顺着指针链表迭代，在直到 NULL 的循环体中，持续对度数累加并往后驱动

算法复杂度与拓扑活跃度

时间复杂度与度数向关联： O(n)

算法未开辟额外动态存储区，因而空间复杂度: O(1)

int CountDegree(int v) const {
    if (v < 0 || v >= vexNum) return -1;
    int degree = 0;
    AdjListNetworkArc<WeightType> *p = vexTable[v].firstarc;
    while (p) {
        degree++;
        p = p->nextarc;
    }
    return degree;
}

图的连通分量计数ConnectedComponent()

外循环迭代与状态标记

为了不改变类内部的原始邻接表数据，开辟局部布尔数组 visited 用于追踪访问状态，外层循环遍历所有顶点

搜索触发与计数机制

每探寻到未被访问过的顶点，即找到了一个新的连通分支，则触发 DFS()，递归标记该连通分支内的全部节点。通过累加变量 count++ ，统计分量数

复杂度分析

时间复杂度： O(V + E)

空间复杂度为分配访问标记所需的规模： O(V)

int ConnectedComponent() const {
    // 创建访问标记局部数组
    bool *visited = new bool[vexNum];
    for (int i = 0; i < vexNum; i++) {
        visited[i] = false;
    }

    int count = 0;
    for (int i = 0; i < vexNum; i++) {
        if (!visited[i]) {
            count++; // 触发新连通分量的 DFS
            DFS(i, visited);
        }
    }

    delete[] visited; // 释放局部堆空间
    return count;
}

Boruvka 算法：分治合并

核心思想与分段合并

将每个点初始化为独立的连通块，每一轮遍历所有块，独立为其寻找一条通往其他块的权重最小的“出边”，通过多路同时合并机制极大地减少合并轮次

复杂度优势

因每轮合并能使全图连通块的数量至少折半，算法最多在 log V 轮后完成，时间复杂度达到 O(E log V)

• 防环校验：从堆顶取出最小出边时，必须再次检查并确保 Find(v1) != Find(v2)，通过后方可执行 Union(v1, v2)

• 循环跳出后若 components > 1，即图非连通

Boruvka 算法实现逻辑

初始化与并查集

利用 UFSets 维护顶点连通性，初始时将每个顶点视为一个独立分量，components 设为顶点总数

跨块最小边检索

遍历所有边，若满足 Find(v1) != Find(v2)，则将该边推入分量根节点专属的优先队列 pqs 中

级联合并

取出堆顶最优边后，必须二次检查两个端点是否仍分属不同分量，防止在已连通导致合并成环

当满足 components == 1 或无法继续合并时跳出，支持生成最小生成森林以应对非连通图

    void Boruvka() {
        if(vexNum <= 0) return;
        typedef BoruvkaEdge<ElemType, WeightType> BEdge;
        ElemType v1, v2;
        WeightType totalWeight = 0;

        // 初始化顶点数据和并查集
        vector<ElemType> kVex(vexNum + 1);
        for (int i = 0; i < vexNum; i++) kVex[i] = vexTable[i].data;
        UFSets<ElemType> f(kVex.data(), vexNum);
        int components = vexNum;
        bool canMerge = true;

        // Boruvka 主循环
        while (components > 1 && canMerge) {
            canMerge = false;
            // 每个分量只记录一条最小出边，-1 表示该分量无出边
            vector<int> cheapest(vexNum, -1);
            vector<BEdge> cheapEdge(vexNum);

            // 遍历所有边，为每个分量找最小出边
            for (int v = 0; v < vexNum; v++) {
                for (int u = FirstAdjVex(v); u >= 0; u = NextAdjVex(v, u)) {
                    GetElem(v, v1); GetElem(u, v2);
                    if (f.Find(v1) != f.Find(v2)) {
                        int root = f.Find(v1);
                        WeightType w = GetWeight(v, u);
                        // 若该分量还没有候选边，或当前边更小，则更新
                        if (cheapest[root] == -1 || w < cheapEdge[root].weight) {
                            cheapest[root] = 1;
                            cheapEdge[root] = {v1, v2, w};
                        }
                    }
                }
            }

            // 尝试合并每个分量的最小出边
            for (int i = 0; i < vexNum; i++) {
                if (cheapest[i] != -1) {
                    v1 = cheapEdge[i].vertex1;
                    v2 = cheapEdge[i].vertex2;
                    if (f.Find(v1) != f.Find(v2)) {
                        cout << "选中边:(" << v1 << "," << v2 << ") 权:" << cheapEdge[i].weight << endl;
                        f.Union(v1, v2);
                        totalWeight += cheapEdge[i].weight;
                        components--;
                        canMerge = true;
                    }
                }
            }
        }
        if (components > 1) cout << "图不连通，生成最小生成森林。" << endl;
        cout << "总权值: " << totalWeight << endl;
    }

Boruvka 算法综合分析

1. 复杂度分析

  • 时间复杂度：O(E log V)
    循环依次连通块数量 components 至少折半，合并主循环至多执行 O(log V) 次，每轮需线性扫描可用邻接边 O(E)
  • 空间复杂度：O(V + E)
    并查集 UFSets 连通状态维护及标记需 O(V) 辅助内存；各连通根分量的优先队列额外占用 O(E)

相比单向合并，Boruvka 支持多路并发合并，在分布式集群计算场景下性能表现优异

2. 核心优缺点对比

  • 核心优势： 算法不需要对边进行全局 O(E log E) 排序；不限于单点单侧盲目扩张，自适应并发构造多连通森林的过程非常直观
  • 算法局限： 在多条边具有相同权值时，必须二次防环和并查集环路判定检测，否则极易形成回路;稠密图常数性能略逊于 Prim 堆优化版

进阶方向：可结合动态并查集，在动态流式网络中实现万级节点的 MST 实时拓扑系统

最小生成树唯一性判定MST Uniqueness Detection

1. 唯一性准则与预处理

  • 核心割准则判定定理：
    对于任何不在树上的非树边 e=(u,v)，其与 MST 唯一路径构成的基本环路中，其权重均 严格大于 环路上的所有其他生成边
  • 边的全局排序：
    对所有边按权值从小到大执行快速排序 O(E log E)，进行同权分组检测

定理支撑：若图的所有边权重均互不相等，则其 MST 必定唯一；等权边的冲突竞争是产生多重最小生成树的唯一根源

2. 同权合并与判定机制

  • 同权跨块边候选统计：
    使用双指针滑动窗口划定同权边集，统计同权边中，有多少条边连接了两个不同的并查集分量
  • 级联合并与冲突：
    并查集实际模拟调用 Union 进行真实连通，并统计被合入生成树的实际边数，若两者不等（即实际边数更少），则 MST 不唯一

几何竞争范例：若同权的三条边形成环路，可选候选数为 3，但实际树中只能容纳 2 条，此时因 2 < 3 所以不唯一

同权边分组处理

所有边升序排列，而后利用滑动窗口确定具有相同权值的边集，对每一组边先统计其可选边，再执行合并

核心判定准则

若某组同权边中， countActuallySelected < countCanSelect，说明存在可替代边，则 MST 不唯一

空间与时间复杂度

时间复杂度：O(E log E)；收集边：O(V + E)；快速排序：O(E log E)；分组模拟合并时：O(E alpha(V))

空间复杂度：O(V + E)；边数组：O(E)；顶点：O(V)

        int countCanSelect = 0;

进阶拓展：Kruskal 重构树Reconstruction Tree

1. 核心概念与结构本质

  • 结构定义： 基于 Kruskal 算法思想，在并查集合并两个连通分量时，不再直接连接，而是新建一个代表「边」的辅助节点作为两者的父节点
  • 结构本质： 将原始网状图通过「维度升迁」转换为一棵包含 2V-1 个节点的二叉树，它将图的「连通轨迹」映射为树的「层次深度」

核心转化：图中两点路径上的「最大边权最小值」，等价于重构树中两点 LCA 节点的点权

2. 算法思想与应用图景

  • 核心思想： 利用边权的单调性建树，构造出一棵点权随深度递减/增的堆式树，通过并查集 O(E alpha(V)) 高速完成树结构的重组
  • 应用场景：
    ● 瓶颈路查询：LCA极速查询图中任意两点间路径的边权限制
    ● 限制可达性：查询仅通过权值 <= K 的边能到达的所有节点子树集合

工业价值：常用于分布式网络链路负载均衡分析、复杂交通流压力测试及大规模社交关系的可达性分级

Kruskal 重构树算法

并查重构与建树化 void Ex_kruskal( )

边权升序排列后，判定若 fau != fav，则分配一个新父节点 cntn++ 代表边，使其点权 val[cntn] = cw；另其左右子树分别悬挂原顶点的并查集根节点，实现图向树的重构

倍增预处理与深搜 void DFS( )

从重构树的各全局根节点向下搜索,利用倍增思想维护 anc[u][i] = anc[anc[u][i-1]][i-1]，代表节点 u 的第 2^i 个祖先，以便在 O(log V) 复杂度下实现节点跳跃查询

最近公共祖先查询 int LCA( )

为求解路径最值，将两顶点对齐至同一深度后，倍增同时上跳到其最近公共祖先 LCA，返回 val[lca(x,y)]，即为整条路径上的瓶颈边权

重构树倍增预处理与初始化

数据结构与并查集

采用并查集管理重构树结构，fa[x] 维护各个分量的上层指向，val[cntn] 承载新重构虚拟父节点点权，对应了合并分量时的路径瓶颈边权值

倍增 DFS( ) 预处理

调用 dfs(根节点, 0) 对每棵重构树初始化，在向下递归的同时，利用动态规划快速维护 anc[u][i] 数组，以实现 O(log V) 的最近公共祖先上跳查询

复杂度与LCA递推方程

递推方程：anc[u][i]=anc[anc[u][i-1]][i-1]

时间复杂度：建立状态时间复杂度为 O(V log V)

#define ll long long
const int N = 2 * (2e5 + 5);
const int LOG = 25;
ll fa[N], depth[N], val[N];
vector<ll> tree[N];
ll anc[N][LOG];

struct edge {
    int u, v, w;
};
bool cmp(edge a, edge b) {
    return a.w < b.w;
}

int find(int x) {
    if (fa[x] == x) return x;
    return fa[x] = find(fa[x]);
}

void dfs(int u, int fa) {
    anc[u][0] = fa; // u的第2^0个祖先
    depth[u] = depth[fa] + 1;
    for (int i = 1; i < LOG; i++) {
        anc[u][i] = anc[anc[u][i - 1]][i - 1];
    }
    for (int i = 0; i < (int)tree[u].size(); i++) {
        if (tree[u][i] != fa) {
            dfs(tree[u][i], u);
        }
    }
    return;
}

建树逻辑与瓶颈查询

Ex_kruskal 建树与树森林DFS

重构建树后对所有连通块根节点执行 dfs，从而对每棵重构树初始化

lca 二进制倍增跳跃

采用二进制拆分将深节点 u 提升至与 v 相同的深度，随后从大步 (1<<24) 开始依次递减尝试迈步，保证两点能同步上升至最近公共祖先的紧邻子节点

求解 solve

find(x) != find(y) 即节点不连通时返回 -1，否则两节点的 LCA 虚拟点权 val[lca(x,y)] 即为该路径上起控制决定的瓶颈边权

void Ex_kruskal() { // 重构树构建
    cntn = n;
    sort(side + 1, side + m + 1, cmp);
    for (int i = 1; i < 2 * n; i++) fa[i] = i;
    for (int i = 1; i <= m; i++) {
        int fau = find(side[i].u), fav = find(side[i].v);
        ll cw = side[i].w;
        if (fau == fav) continue;
        cntn++;
        fa[fau] = fa[fav] = fa[cntn] = cntn; // 并查集更新
        val[cntn] = cw;
        tree[cntn].push_back(fau);
        tree[cntn].push_back(fav); // 建树
        if (cntn == 2 * n - 1) break;
    }
    for (int i = cnt; i <= cntn; i++) {
        int x = find(i);
        if (vis[x]) continue;
        dfs(x, 0);
        vis[x] = 1;
    }
}

ll lca(int u, int v) {
    if (depth[u] < depth[v]) swap(u, v);
    int diff = depth[u] - depth[v]; // u需要向上跳diff步
    for (int i = 0; i < LOG; i++) {
        if (diff & (1 << i)) u = anc[u][i];
    }
    if (u == v) return u; // 找到公共祖先了
    for (int i = LOG - 1; i >= 0; i--) { // 先迈大步
        if (anc[u][i] != anc[v][i]) {
            u = anc[u][i];
            v = anc[v][i];
        }
    }
    return anc[u][0];
}

void solve() {
    cin >> x >> y;
    if (find(x) != find(y)) {
        cout << -1 << endl;
        return;
    }
    cout << val[lca(x, y)] << endl;
}

算法对比与分析

1. 传统 MST 暴力求解 (树上遍历)

  • 时间复杂度：O(V) 单次查询
    无额外初始化，但每次需 DFS 遍历，复杂度为 O(V)
  • 空间复杂度：O(V + E)
    仅需维护基本生成树的邻接表拓扑空间，无需建立复杂的状态索引或倍增指针结构，内存占用小
  • 核心局限：树上简单路径唯一但无单调顺序，多次检索时会重复寻路遍历

使用场景：生成树拓扑极小且查询少的单次查询系统

2. Kruskal 重构树 + 倍增 LCA

  • 时间复杂度：O(log V) 单次查询
    O(V log V) 重构建树与倍增预处理，此后单次 LCA 查询通过二进制跳跃仅需 O(log V)
  • 空间复杂度：O(V log V)
    需维护额外 2N 规模的重构二叉树结构，以及保存深度、点权和存储 anc[2N][25] 的倍增阶梯树辅助空间
  • 绝对优势：建立具有权值堆性质的二叉树，将问题转化为了常规的查询 LCA 点权

使用场景：分布式网络规划、高数量级拓扑网瓶颈计算等
